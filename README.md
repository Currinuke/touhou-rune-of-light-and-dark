《东方光暗符》（Touhou: Rune of Light and Dark）是由[空空如也ABC_REN](https://space.bilibili.com/422560604)创作的，将上海爱丽丝幻乐团的《东方Project》游戏系列及其衍生系列的角色、世界观等元素代入进《Deltarune》的同人项目，其正典内容包含文字设定概念及其相关画作、动画等。

本Kristal项目为对《东方光暗符》相关正典内容的非官方还原项目，由[是加里也是咖喱](https://space.bilibili.com/1026361503)（即[Currinuke](https://space.bilibili.com/1026361503)）创建。
